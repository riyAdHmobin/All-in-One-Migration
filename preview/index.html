      How scheduled backups work

      • They run in the background, so this page doesn't need to be open.
      • Only one backup or import runs at a time. A scheduled backup waits if another job is running.
      • If the site was down at the scheduled time, the missed backup runs once when it's back, not several times.
      • Results appear on the Backups tab with a “Scheduled” label.
